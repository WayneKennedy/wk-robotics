# Contributing

This project is open source and contributions are welcome; it lives in the wk-robotics repository under `projects/devastator/`. It is at the design-record
stage; nothing is built (see [*Devastator Open Questions*](memory://main/robotics/devastator/devastator-open-questions)).

- **Read first:** [`AGENTS.md`](AGENTS.md) (how this repo is organised) and
  [*Devastator Concept*](memory://main/robotics/devastator/devastator-concept) (what is being built and why).
- **Every artefact meets the 4Cs** — Correct, Complete, Coherent, Concise (see `AGENTS.md`).
- **Record durable decisions** in [*Devastator Decisions*](memory://main/robotics/devastator/devastator-decisions); raise
  unresolved ones in [*Devastator Open Questions*](memory://main/robotics/devastator/devastator-open-questions). Never let a
  project fact live only in chat.
- **Measured beats plausible.** Figures carry the date and the conditions they were taken
  under; an unverified figure is labelled as one.
- **Licensing:** contributions are accepted under the repo's tri-licence
  ([`LICENSING.md`](LICENSING.md)). Add an `SPDX-License-Identifier` header to new
  source files.
