# Contributing

This project is open source and contributions are welcome; it lives in the wk-robotics repository under `projects/soarm101/`. It is a **build record** of an
upstream design. Upstream-wide design changes belong at
[TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100). Local,
owner-requested prototypes may live here with pinned provenance, explicit status,
appropriate licences and validation limits; see the
[lightweight study](cad/lightweight-v1/README.md).

- **Read first:** [`AGENTS.md`](AGENTS.md) (how this repo is organised) and
  [`docs/concept.md`](docs/concept.md) (what is being built and why).
- **Every artefact meets the 4Cs** — Correct, Complete, Coherent, Concise (see `AGENTS.md`).
- **Record durable decisions** in [`docs/decisions.md`](docs/decisions.md); raise
  unresolved ones in [`docs/open-questions.md`](docs/open-questions.md). Never let a
  project fact live only in chat.
- **Measured beats plausible.** Figures carry the date and the conditions they were taken
  under; an unverified figure is labelled as one.
- **Licensing:** contributions are accepted under the repo's tri-licence
  ([`LICENSING.md`](LICENSING.md)). Add an `SPDX-License-Identifier` header to new
  source files.
